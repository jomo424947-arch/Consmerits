# 🏪 نظام بيع وجرد لمحل مستحضرات التجميل (Cosmetics POS & Inventory System)

> برنامج ويندوز ديسكتوب يعمل بالكامل **أوفلاين 100%** على جهاز المحل، مبني وفق أعلى معايير الأمان وسرعة البيع بالباركود وإدارة الصلاحية (FEFO).

---

## 🏗️ الهيكل البرمجي المعتمد (Project Architecture)

تم تجهيز هيكل المشروع بالكامل طبقاً لوثائق المشروع (`docs/00` إلى `docs/11`) دون كتابة أكواد منطق تجاري مسبقة، ليكون جاهزاً للانطلاق مرحلياً:

```
├── docs/                        # وثائق ومخططات المشروع الـ 12
├── tests/                       # اختبارات النظام
│   ├── unit/                   # اختبارات الوحدة الحسابية والباركود
│   ├── integration/            # اختبارات تكامل قاعدة البيانات والـ Triggers
│   └── e2e/                    # اختبارات تدفق البيع الكامل
├── src/
│   ├── main/                   # العملية المركزية (Electron Main Process)
│   │   ├── db/                 # اتصال SQLite، إعدادات WAL، و Migrations
│   │   │   └── migrations/     # ملفات ترحيل الجداول والـ Triggers
│   │   ├── services/           # الخدمات المنطقية (Sales, Inventory, Cash...)
│   │   ├── ipc/                # معالجات قنوات IPC والتحقق بـ Zod
│   │   │   └── handlers/       # معالجات كل قسم مفصولة
│   │   ├── printing/           # محركات طباعة الإيصالات 80mm والباركود
│   │   └── index.ts            # نقطة دخول Main Process
│   ├── preload/                # عزل الحماية الآمن (contextBridge)
│   │   └── index.ts            # واجهة window.electron الآمنة
│   ├── shared/                 # الأنواع والثوابت المشتركة
│   │   ├── constants/          # الصلاحيات، القنوات، والإعدادات القياسية
│   │   ├── types/              # تعريفات TypeScript لكافة الجداول والكيانات
│   │   ├── schemas/            # مخططات Zod للتحقق من المدخلات
│   │   └── utils/              # دوال حساب القروش، التواريخ، وباركود EAN-13
│   └── renderer/               # واجهة المستخدم (React + TypeScript RTL)
│       ├── assets/             # الخطوط المحلية والأيقونات الأوفلاين
│       ├── components/
│       │   ├── common/         # أزرار، حقول، نوافذ، وجداول موحدة
│       │   └── layout/         # القائمة الجانبية، الهيدر، وشريط الحالة
│       ├── features/           # شاشات النظام المتخصصة
│       │   ├── pos/            # شاشة البيع السريع ونقطة الكاشير
│       │   ├── products/       # إدارة الأصناف، الدرجات، والباركود
│       │   ├── inventory/      # المخزون، الصلاحية، والجرد الدوري
│       │   ├── purchases/      # فواتير التوريد وحسابات الموردين
│       │   ├── returns/        # المرتجعات والاستبدال
│       │   ├── cash/           # إدارة الورديات، الخزنة، والمصروفات
│       │   ├── reports/        # التقارير اليومية والأرباح
│       │   ├── settings/       # بيانات المحل والنسخ الاحتياطي
│       │   └── auth/           # تسجيل الدخول بـ PIN والصلاحيات
│       ├── lib/                # أدوات الاتصال بالـ IPC والمساعدات
│       ├── styles/             # نظام التصميم (Design System RTL)
│       ├── App.tsx             # التوجيه والتنقل بين الشاشات
│       └── main.tsx            # نقطة تركيب React
├── package.json                # التبعيات والأوامر
├── tsconfig.json               # إعدادات TypeScript ومسارات الاختصار
├── vite.config.ts              # إعداد بناء Electron + React عبر Vite
└── .gitignore                  # استبعاد الملفات المؤقتة وقاعدة البيانات
```

## 📋 خطة التنفيذ المرحلية (Roadmap)

1. **المرحلة 0 & 1:** البنية التحتية وقاعدة البيانات SQLite، إعداد الـ Migrations، واختبارات العمليات الحسابية والـ Triggers.
2. **المرحلة 2:** شاشة البيع (POS) — نقطة القرار الأولى للعميل (مسح الباركود، السلة، وطباعة الإيصال).
3. **المرحلة 3:** المخزون والصلاحية (FEFO)، الاستيراد من Excel، وفواتير المشتريات.
4. **المرحلة 4:** الخزنة والورديات، تقرير Z-Report، والتقارير ولوحة التحكم.
5. **المرحلة 5:** الاختبارات الشاملة (Crash Test) وبناء ملف التثبيت المستقل `setup.exe`.
