# Database Migrations

هذا المجلد يحتوي على ملفات ترحيل قاعدة بيانات SQLite المرقمة تسلسلياً.

## القواعد الأساسية:
1. كل ملف SQL مرقم بتنسيق `00X_name.sql`.
2. لا يتم تعديل أي ملف migration بعد تشغيله أو نشره إطلاقاً.
3. يتم تتبع آخر إصدار مطبق في جدول `schema_version`.
4. أي تعديل مستقبلي في الجداول يتم عبر ملف migration جديد برقم جديد.
